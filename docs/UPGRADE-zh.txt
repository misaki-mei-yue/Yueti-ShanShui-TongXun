山水通讯 1.5.4 使用和升级说明

本批包含 Windows Setup、Android APK、服务器 tar.gz 和配套部署 sh。
先覆盖安装新版 Windows 和 Android 客户端，再升级服务器。网页版刷新页面即可。

服务器升级
把 YuetiShanShui-1.5.4-server.tar.gz 和本批 deploy-shanshui-opt.sh
上传到 /opt/shanshui，覆盖同名旧脚本。用 root 执行：

  bash /opt/shanshui/deploy-shanshui-opt.sh

继续用原账号登录；升级保留账号、好友、加密身份、聊天、附件与配置。
已经接通的 chat.misakimei.cn 不需要再次配置。
Windows 与 Android 直接覆盖安装，保留本机账号和旧密钥迁移信息。
不要卸载客户端或删除 data、config、current 来升级。
tar.gz 是压缩的 tar 包，脚本直接识别，无需手动解压。
本次需要同批 sh 与 tar；旧客户端也请更新，避免版本不兼容。
新版客户端可连接 1.5.0、1.5.1、1.5.3 和 1.5.4。各端升级到 1.5.4 后即可使用以下功能。

找同一个人的聊天
  从消息列表点一次联系人的名字就能查看双方历次私聊。旧版单独创建的
  双人带山岚会话也会在这里显示。新消息默认发到当前私聊，旧记录和附件
  沿用各自的加密权限。需要解锁归档时，从这段对话的「旧聊天记录」进入。
  曾有其他真人参加的群聊保留自己的会话。显示同名的不同账号各有独立入口。

在会话里设置山岚
  打开私聊或群聊，点右上角「会话详情」可以查看山岚的授权状态，并切换
  「暂停我在此会话的山岚调用」。这个选择会同步到你自己的其他设备。
  管理员可在同一位置进入「模型与私聊账号授权」或「模型与本群授权」。
  授权后可从输入框旁点「@山岚」，或者在详情中点「向山岚提问」。

恢复历史聊天
  在归档会话顶部点「恢复旧记录」。已经恢复过旧身份的 1.5.1 设备请至少用新版
  登录一次，以便同步其记住的旧密钥。若没有记住，可导入当时保存的旧版恢复码。
  当前身份会在设备上加密保护解锁资料。看到「已同步到账号」后，其他端用同一
  账号登录即可查看。离线时先在本机解锁，恢复连接后重试同步。
  如果丢失旧码，选择仍能阅读这段归档的好友请求协助。支持双人私聊、旧版
  加过山岚的双人会话及多人群。好友只可授权双方原本就能阅读的消息与附件。
  私人笔记和与山岚的单聊可用自己的旧身份恢复。没有任何原解密密钥的内容
  无法重建。仅锁定本机时，需先使用登录密码解锁。

山岚授权
  设置 → 山岚 AI → 模型设置。个人授权适用于该账号的双人私聊及山岚单聊。
  群聊单独授权，管理员可看到群名和成员，无需加入群或查看消息。
  山岚不计入群人数。两位真人的旧会话继续使用原有消息和附件。
  勾选群并保存时，已建立加密身份的成员会收到加密配置。新增成员或成员重建
  身份后，请在管理员设备再保存一次授权。已发到设备的共享 Key 可以被提取；
  要使旧 Key 失效，请在服务商处轮换。模型服务商会收到用户交给山岚的内容。

数据库升级到格式 6。旧版程序会拒绝直接打开升级后的数据。请保留部署备份。

1.5.0 的变化：账户密码解锁
新账号无需生成或保存任何恢复码。账号密码即用于登录和加密身份解锁，
默认记住设备。旧账号在原已解锁/仍有记住设备信息的客户端登录，可用
账号密码完成迁移并保留旧密钥、历史、AI 设置。若原密钥确实全部丢失，
使用旧账号密码登录后选择“原恢复码已丢失，重新启用聊天”，勾选确认。
旧会话和密文不会删除，但不能用新密钥直接解密原本属于旧密钥的内容；
1.5.1 可使用上面的旧码恢复或好友协助方式尝试恢复旧聊天。
已记录的联系人身份变更需要核对新安全码；管理员丢失旧钥后重新配置山岚并授权。
切换密码时新版同步重新加密密钥保护记录。

隐私取舍：登录密码现在同时保护加密密钥。服务器正常存储的仍是消息和
私钥密文；旧版通过独立恢复码抵抗服务器捕获登录密码的能力不再保留。
能取得登录密码及密钥备份的一方可能解密聊天，请使用强密码。

1.4.1 的变化
附件取消固定 20 MB 总大小上限，改为分块端到端加密传输。上传显示进度，
可以停止和重试。实际仍受磁盘空间和网络限制，旧附件继续正常读取。
大文件保存先选择位置，校验完整后完成；不支持大文件保存的浏览器会提示
改用 PC/APK 或新版 Chrome/Edge。现有 26m 域名代理限制可保留。

APK 安装后到“设置 → 消息提醒 → 声音与后台通知”点“开启消息提醒”，
允许安卓的通知权限。后台连接有持续通知，新消息可声音、震动并点击进入
会话；通知不显示原文。安卓强停、省电限制或断网时可能延迟，重开可恢复。
附件菜单中的“照片”直接打开系统相册，“文件”打开系统文件选择器。

本版继续保留以下 1.4 系列功能与配置。

配置山岚
打开“设置 → 山岚 AI → 模型设置”。原文字模型与已有授权会保留。
新增可选的“看图模型”和“生图模型”，展开后启用并填写模型名称。
可分别配置接口与普通 Key，也可复用文字模型的接口与 Key。
第一次留空 Key 使用文字 Key；之后留空保留该项已保存的 Key。
保存时配置在管理员设备上加密，再授权给勾选的用户设备。
不需要 OpenRouter，不需要管理密钥，不增加每次 0.25 美元的软件限制。
服务商须支持对应的 chat/completions 图片输入或 images/generations 接口。

使用方式
1. 看图：私聊山岚，附加图片并提问；只发图片时默认让山岚描述它。
2. 生图：点击“画一张”，或发“/生图 雨中的江南小巷”。
   手机点“＋ → 请山岚画图”。也能说“帮我画一张……”。
   一次生成一张；只发送本次描述，暂不提供图生图和改图。
3. 普通双人好友会话自带 @山岚，不用另建带 AI 的群。
   未召唤时不会自动请求 AI；默认只分享当前问题，可用 /10 指定前文。
4. 山岚可在适合的时候发内置表情，不会每条回答都发。
5. 私聊长期记忆默认开启，回复后提取个人偏好等稳定信息。
   “设置 → 山岚的长期记忆”可查看、添加、修改、忘记、暂停或清空。
   这是摘要式记忆，并非逐字保存所有对话；提取会额外调用文字模型。
   私人记忆加密同步至同一账户，不带入好友或群聊。
6. Tavily 继续使用已有设置，用户自行开启联网搜索；只搜索当前问题。

隐私与接入范围
问题、当前附带图片和生图描述由设备直接交给所配置的服务商。
回复、生成图与记忆在设备上加密后同步；聊天服务器不接收这些原文。
服务商仍会处理主动交给它的内容。管理员 Key 遮盖显示，普通用户界面
不显示 Key；获准设备持有人仍有能力提取共享 Key。
网页版还需要模型服务商允许跨域；PC/APK 通过原生网络直连。
不会为兼容跨域而把模型或 Tavily 原文改由阿里云聊天服务器转发。
停止请求或锁定会取消本机正在进行的请求；已交给服务商的内容不能收回。
