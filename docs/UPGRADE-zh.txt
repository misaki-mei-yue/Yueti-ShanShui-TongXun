山水通讯 1.4.1 使用和升级说明

本批包含 Windows Setup、Android APK、服务器 tar.gz 和配套部署 sh。
先升级服务器，再覆盖安装两端客户端；网页版重新加载页面即可。

服务器升级
把 YuetiShanShui-1.4.1-server.tar.gz 和本批 deploy-shanshui-opt.sh
上传到 /opt/shanshui，覆盖同名旧脚本。用 root 执行：

  bash /opt/shanshui/deploy-shanshui-opt.sh

继续用原账号登录；升级保留账号、好友、加密身份、聊天、附件与配置。
已经接通的 chat.misakimei.cn 不需要再次配置。
Windows 与 Android 直接覆盖安装，保留本机账号和恢复信息。
不要卸载客户端或删除 data、config、current 来升级。
tar.gz 是压缩的 tar 包，脚本直接识别，无需手动解压。
本次需要同批 sh 与 tar；旧客户端也请更新，避免版本不兼容。

1.4.1 的变化
附件取消固定 20 MB 总大小上限，改为分块端到端加密传输。上传显示进度，
可以停止和重试。实际仍受磁盘空间和网络限制，旧附件继续正常读取。
大文件保存先选择位置，校验完整后完成；不支持大文件保存的浏览器会提示
改用 PC/APK 或新版 Chrome/Edge。现有 26m 域名代理限制可保留。

APK 安装后到“设置 → 消息提醒 → 声音与后台通知”点“开启消息提醒”，
允许安卓的通知权限。后台连接有持续通知，新消息可声音、震动并点击进入
会话；通知不显示原文。安卓强停、省电限制或断网时可能延迟，重开可恢复。
附件菜单中的“照片”直接打开系统相册，“文件”打开系统文件选择器。

本版继续保留以下 1.4 系列功能与配置。

配置山岚
打开“设置 → 山岚 AI → 模型设置”。原文字模型与已有授权会保留。
新增可选的“看图模型”和“生图模型”，展开后启用并填写模型名称。
可分别配置接口与普通 Key，也可复用文字模型的接口与 Key。
第一次留空 Key 使用文字 Key；之后留空保留该项已保存的 Key。
保存时配置在管理员设备上加密，再授权给勾选的用户设备。
不需要 OpenRouter，不需要管理密钥，不增加每次 0.25 美元的软件限制。
服务商须支持对应的 chat/completions 图片输入或 images/generations 接口。

使用方式
1. 看图：私聊山岚，附加图片并提问；只发图片时默认让山岚描述它。
2. 生图：点击“画一张”，或发“/生图 雨中的江南小巷”。
   手机点“＋ → 请山岚画图”。也能说“帮我画一张……”。
   一次生成一张；只发送本次描述，暂不提供图生图和改图。
3. 普通双人好友会话自带 @山岚，不用另建带 AI 的群。
   未召唤时不会自动请求 AI；默认只分享当前问题，可用 /10 指定前文。
4. 山岚可在适合的时候发内置表情，不会每条回答都发。
5. 私聊长期记忆默认开启，回复后提取个人偏好等稳定信息。
   “设置 → 山岚的长期记忆”可查看、添加、修改、忘记、暂停或清空。
   这是摘要式记忆，并非逐字保存所有对话；提取会额外调用文字模型。
   私人记忆加密同步至同一账户，不带入好友或群聊。
6. Tavily 继续使用已有设置，用户自行开启联网搜索；只搜索当前问题。

隐私与接入范围
问题、当前附带图片和生图描述由设备直接交给所配置的服务商。
回复、生成图与记忆在设备上加密后同步；聊天服务器不接收这些原文。
服务商仍会处理主动交给它的内容。管理员 Key 遮盖显示，普通用户界面
不显示 Key；获准设备持有人仍有能力提取共享 Key。
网页版还需要模型服务商允许跨域；PC/APK 通过原生网络直连。
不会为兼容跨域而把模型或 Tavily 原文改由阿里云聊天服务器转发。
停止请求或锁定会取消本机正在进行的请求；已交给服务商的内容不能收回。
