本次新增
  附件不再固定限制 20 MB。大文件按 4 MiB 分块加密、签名、上传和下载，
  不会在服务器内存中一次装入整个文件。实际大小取决于服务器、接收设备
  的可用磁盘和网络；服务器空间不足会停止并提示。可查看上传进度、停止
  和重试；中断时可能需要重新选择原文件，不承诺跨重启断点续传。
  旧附件仍能解密，大附件和小附件都不会把原文与原始文件名交给服务器。
  保存大文件时先选择目标位置，完整校验通过后才完成；取消或失败清理
  临时文件。网页版大文件保存需支持 showSaveFilePicker 的浏览器；若
  浏览器不支持，会提示使用 Windows/Android 客户端或新版 Chrome/Edge。
  现有 26m 反向代理限制可以保留，分块请求小于它，无需重新接域名。

  Android 在“设置 → 消息提醒 → 声音与后台通知”中开启消息提醒，允许
  系统通知权限后，可以在后台保持连接。新消息按安卓通知设置播放声音、
  震动并显示系统通知；点击进入相应会话。通知不展示消息原文。
  自己发送的消息、已读消息、免打扰会话、当前正在阅读的会话不重复提醒。
  后台连接会保留一条持续通知；请允许应用后台运行。系统强行停止应用、
  省电限制、断网或会话过期时不能保证实时提醒，重新打开会恢复连接。
  通知连接只访问你自己的聊天服务器，不引入第三方推送平台或上传解密密钥。

  附件菜单已分成“照片”和“文件”。Android 的照片入口打开系统相册选择器，
  文件入口打开系统文档选择器；只获得你选择的项目，无需整个相册读取权限。

注册进入同一空间不等于成为好友。联系人只列已通过申请的朋友。
在“添加朋友”输入对方完整用户名或账号并点击搜索，命中后发送申请，
对方在“新的朋友”接受后才能私聊。空白页不展示全站名单，前缀、昵称和
模糊关键词不会列出陌生人。查找次数按账号与网络来源限制，避免批量探查。
收到申请可拒绝，发出的申请可撤回；对方同时发来申请不会自动同意。
好友可解除关系，解除后停止私聊新消息，原有聊天和加密记录保留。
升级不会自动把旧私聊变成好友；旧记录可读，继续聊天需补一次好友确认。
私聊创建、复用、消息和附件权限由服务器检查，不能绕过界面发给陌生人。
新建群或新增群成员只选择自己的好友；已有群不因好友关系变化而解散。
山岚私聊、个人笔记正常使用，原端到端加密和 AI 直连方式继续保留。

山岚回答方式
  本版在设备上自动加入固定系统提示：优先回答当前问题，先给答案和做法；
  把已选择的资料消化成回答，默认不逐条介绍引用材料或附长篇来源清单。
  用户明确要出处、原文或详细解释时仍正常提供，不编造来源和联网结果。
  不会为了简短省略必要步骤，也不会为了改善回答而自动分享更多聊天。
  系统提示随网页、Windows 和 Android 客户端一起更新，无需手动填写。
  提示词能改善回答风格与聚焦；准确性仍取决于所配置模型及提供的上下文。

管理员统一付费的 AI 设置
  打开“设置 → 山岚 AI → 模型设置”。
  填 API 地址和服务商提供的普通 API Key，如 https://ai.isok.dev/v1。
  点击“读取模型”，选择模型；接口不支持列举模型时可手动填写模型名称。
  勾选允许使用山岚的账户后保存，不需要 OpenRouter 或管理密钥。
  Key 在管理员设备上加密并签名，服务器仅保存密文；获准账户登录解锁后
  在本机取得 Key，直接调用所配置服务商。普通用户界面不显示 Key。
  管理员输入也遮盖显示；重新打开设置时 Key 留空，保存会保留已有 Key。
  本机不明文持久保存 Key，关闭设置或锁定时清除引用；恢复码仍需妥善保存。
  用户设备的实际持有人仍有能力提取 Key 并在软件外使用，这是共享普通
  Key 的边界。请选择专用 Key，并在服务商设置余额、额度及模型权限。
  无每次 $0.25 的软件限制或五分钟临时授权；实际费用和限额由服务商管理。
  新账号先登录并建立加密身份，管理员回来勾选并保存授权，不必重新输入 Key。
  取消授权不能收回已取得的 Key；彻底撤销请在服务商更换 Key 后重新保存。
  首次使用及 API 地址变化时需确认实际模型服务地址；管理员签名、指纹及
  配置历史校验失败时停止直连，不静默改为聊天服务器转发。
  设备须能直接访问接口。网页版还需服务商允许跨域（CORS）；不支持时
  使用新版安装客户端，软件不会为兼容跨域而通过聊天服务器转发原文。
  服务商和实际模型提供商会处理 AI 原文。服务商的日志与基础设施策略
  由该平台决定；本软件不能保证第三方不记录，也不能保证其不使用阿里云。
  本设计避免原文经过你自己的阿里云聊天服务器。
  Tavily 搜索已恢复为设备直连。管理员在模型设置中填 Tavily Key，勾选
  允许搜索后保存；Tavily Key 同样加密并签名授权，不在普通用户界面显示。
  用户在会话里打开“联网”，仅把当前问题（最多 1,000 字）直接交给 Tavily，
  搜索默认关闭，前文与附件不交给搜索服务。摘要只作为外部资料交给模型，
  不自动打开结果网页。搜索失败会显示原因，用户可重试或关联网后再提问。
  你的聊天服务器不接收搜索原文，Tavily 与模型服务商会处理各自收到的内容。

  AI 私聊普通文字自动回复；双人好友聊天默认也可以召唤山岚，不用另建群。
  双人或含山岚的群聊点击 @山岚 或手动 @ai、@AI、@山岚
  默认只交给模型当前问题。/10 问题交给模型前十条加当前问题，/5 同理。
  指定前文范围 1–199 条；先取最近 N 条，再排除屏蔽、错误及不可解密记录，
  不补入更早消息。AI 前文设置只在此账户本机加密保存。
  本次提问附带的图片会交给看图模型；其他附件和历史图片不自动分享。
  问题从用户设备直达模型，回复在本机加密后发入会话，标记由发起成员分享。

多模态模型设置与使用
  管理员在模型设置中保留文字模型，展开“看图模型”“生图模型”分别启用。
  每项可单独填 API 地址、普通 API Key 与模型名称；首次留空地址和 Key
  会沿用文字模型的设置，之后 Key 留空会保留该项已保存的 Key。
  看图模型需支持 chat/completions 的图片输入；生图模型需支持
  images/generations，返回 PNG、JPEG 或 WebP 的 base64 或下载地址。
  支持这些兼容接口的服务商均可接入；不强制使用 OpenRouter。
  不支持直接接入仅提供异步任务、专有绘画协议、视频或语音的接口。
  看图：向山岚私聊附加图片并提问，只发图片时默认请它描述图片。
  好友会话附加图片后 @山岚 提问。图片在设备上缩放后直达看图接口。
  生图：点“画一张”，手机点“＋ → 请山岚画图”，或输入
    /生图 雨中的江南小巷
    @山岚 帮我画一张雨中的江南小巷
  生图只发送这次描述，不自动附带聊天历史、图片、搜索结果或私人记忆。
  本版一次生成一张图；图片由设备下载、检查并加密后发入聊天。
  模型偶尔可选择一张内置表情，表情同样经端到端加密发送。
  暂不支持图生图或修改已有图片；看图与文字生图是两个独立入口。

山岚的长期记忆
  每个账户有自己的加密记忆，仅用于这个账户与山岚的单独私聊。
  默认开启：回复后整理稳定的偏好和个人信息，再从中检索与下次问题
  相关的内容。它保存事实摘要，不保证逐字记住所有历史对话。
  “设置 → 山岚的长期记忆”可查看、添加、修改、忘记或暂停；暂停后
  不读取也不新增，已有条目保留。清空不会删除聊天记录。
  记忆由设备加密签名，同一账户的其他解锁设备可同步；服务器仅存密文。
  好友和群聊召唤山岚不会携带这份私人记忆。
  提取记忆会产生一次额外的文字模型请求；提取失败不影响已显示的回复。
  模型服务商会处理当次私聊输入、回复与参与回答的相关记忆。
  记忆提取规则和 BM25 检索适配自 QwenPaw 使用的 ReMe；不需要在服务器
  安装 QwenPaw/Python/向量数据库。来源和许可证见 THIRD-PARTY-NOTICES.txt。

恢复码、安全码与设备
  恢复码不同于账户密码，由设备生成，用于解锁加密私钥；不上传服务器。
  “设置 → 聊天加密与恢复 → 安全设置”可查看本设备状态、完整安全码，
  已解锁时可主动显示或复制恢复码。默认遮盖，关闭或切后台会隐藏。
  请单独保存恢复码及加密恢复文件；恢复文件仍需要恢复码才能解锁。
  换设备登录同一账户后输入恢复码即可解锁。登录密码重置不能解密消息。
  失去恢复码且没有已解锁设备时，服务器与管理员无法恢复聊天正文。
  “记住此设备”使用本机不可导出的密钥包裹恢复码，仅用于可信个人设备。
  本机被控制时，攻击者仍可能读取已解锁内容；锁定会清除页面内容和图片缓存。
  复制到剪贴板、下载的文件、截屏属于独立副本，锁定无法撤回它们。
  当前每账户共用长期加密身份，尚无单设备撤销或前向保密的双棘轮协议。

  与联系人通过见面、电话等另一可信渠道核对完整安全码，再确认首次信任。
  成员目录、公钥指纹或签名不匹配时停止发送，不降级明文。
  群主签名确认实际加密成员；新成员无法解密加入前消息，移除后收不到新密文。
  已收到的历史内容不能远程收回。首次仅点确认、未另行核对，不能排除目录冒充。

私密范围
  正文、引用、文件名、类型和附件由发送设备加密、签名，接收设备验证并解密。
  新聊天服务器只保存密文；草稿、待发队列、收藏表情在本机按账户加密保存。
  搜索在本机执行，搜索词不上传；更早历史需先加载。旧历史标为旧版未加密。
  阿里云仍能看到 IP、公开头像昵称、群名、成员关系、时间、文件大小与流量。
  安装版内置界面和加密库，不从聊天服务器下载执行代码；网页代码由服务器提供，
  需要信任该服务器没有修改前端。重视私密时优先安装版并核对联系人安全码。
  未经独立第三方安全审计，不能声称万无一失或匿名、无法追踪。

日常使用
  点击左下角头像可上传、缩放、拖动取景并保存；取消不会上传。
  手机发送保持输入焦点，可连续聊天；群聊 @山岚 按钮直接可见。
  发送后立即显示待发消息，确认送达时沿用同一个节点，保持输入焦点。
  翻看旧记录时新消息不拉走画面，可点击提示回到最新；图片加载保留位置。
  发送时间从发送设备写入签名密文，确认和重试不改显示时间；旧记录仍按
  服务器原时间显示。设备时间不准仍会影响显示，请开启系统自动日期与时间。
  当前会话优先更新，已经验证且未变化的密文复用解密结果，减少显示等待。
  点击笑脸可选常用表情、初始表情或从相册添加 PNG、JPEG、WebP、GIF。
  11 张初始表情随各端打包，现有和新账号均可使用，不重复占每账户收藏空间；
  发送时与自定义图片一样端到端加密。自定义表情继续保留。
  聊天图片在本机解密后显示，可放大、保存或收藏为表情。
  自定义表情每张最大 3 MB，最多 80 张、总计 40 MB，只在当前设备加密保存。
  在“添加朋友”搜索完整用户名或账号，申请通过后可私聊；群主可邀请自己的好友。
  注册需要邀请码，首次建管理员还需要部署口令。
  山水、雪花、樱花、水纹和书法设置继续保留。商用字体不随包分发，
  可导入本人有权使用的字体；缺字体时界面显示实际回退情况。
